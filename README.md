# 📦 WishBox

**여기저기 흩어진 "사고 싶은 것"들을 한 곳에 모아두는 상자**

쇼핑몰, SNS, 친구 추천 등 여기저기서 생기는 "이거 사고 싶다"는 마음을 한 군데에 모아두고, 지금 뭘 먼저 사면 좋을지 판단하기 쉽게 도와주는 개인용 위시리스트 웹앱입니다.

---

## 😩 이런 고민에서 시작했어요

- 위시리스트가 여러 사이트에 흩어져 있어서, 정작 뭘 사려고 했는지 까먹는다.
- 사고 싶은 게 여러 개일 때 뭘 먼저 살지 정하기 어렵다.
- "당장 필요한 것"과 "그냥 갖고 싶은 것"이 뒤섞여 있어서, 하나의 기준(가격순, 최신순 등)만으로는 우선순위가 잘 안 맞는다.

**WishBox**는 항목마다 "필요도"와 "욕구"를 따로 입력받아서, 이 두 가지를 함께 고려한 우선순위로 무엇을 먼저 사면 좋을지 한눈에 보여줍니다.

---

## ✨ 주요 기능

### 1. 위시 항목 기록
- 상품명, 구매 링크, 가격, 이미지(첨부 또는 링크), 비고를 입력해 항목을 추가/수정합니다.
- 이미지가 없으면 카테고리 색상 기반의 기본 아이콘이 대신 표시됩니다.
- 항목 카드를 탭하면 바로 수정 화면이 아니라 **상세 보기 모달**이 뜨고, 여기서 구매 링크를 "바로가기" 버튼으로 복붙 없이 새 탭에서 열 수 있습니다. 수정하고 싶을 땐 상세 모달의 "수정" 버튼을 따로 누르면 됩니다.

### 2. 카테고리로 분류하고 필터링
- 항목마다 원하는 만큼 카테고리를 붙일 수 있고, 입력 중에 바로 새 카테고리를 만들 수 있습니다. 카테고리 선택란에는 "(여러 개 선택 가능)" 안내가 항상 붙어 있어요.
- 처음 접속하면 "생필품", "의류", "취미" 3개의 기본 카테고리가 자동으로 준비되어 있고, 이름·색상 수정이나 삭제도 다른 카테고리와 똑같이 자유롭게 할 수 있습니다.
- 상단 카테고리 필터 바에서 여러 개를 선택해 원하는 항목만 모아볼 수 있고, 이때 상단 요약("사고 싶은 것 총 N개 · 합계 금액")도 선택한 카테고리 기준으로 다시 계산됩니다.
- 별도의 "카테고리 관리" 화면에서 이름·색상 수정, 삭제(연결된 항목에서도 함께 제거)를 할 수 있습니다.

### 3. 필요도 × 욕구, 2축 우선순위 매트릭스
항목을 추가할 때 "필요도"와 "욕구/만족도"를 각각 1~5점으로 선택하면, 아래 2×2 매트릭스 중 어디에 해당하는지 바로 보여줍니다.

| | 욕구 낮음 | 욕구 높음 |
|---|---|---|
| **필요도 높음** | 꼭 필요해요 | 지금 사요 |
| **필요도 낮음** | 다시 생각해봐요 | 천천히 사도 돼요 |

- 필요도 힌트: *"이게 없으면 지금 생활에 불편함이 있나요?"*
- 욕구 힌트: *"이걸 가지면 얼마나 기쁠 것 같나요?"*

### 4. 살 것 / 산 것, 탭으로 구분
- "살 것" 탭에서는 아직 안 산 항목만, "산 것" 탭에서는 체크 완료한 항목만 모아봅니다.
- 카드마다 체크박스 옆에 "구매완료" 라벨이 붙어 있어서, 체크하면 무슨 뜻인지 바로 알 수 있어요. 체크하면 바로 "산 것"으로 이동하고, 3초간 "되돌리기" 스낵바가 떠서 실수로 체크해도 바로 되돌릴 수 있습니다.
- 롱프레스 또는 좌우로 스와이프하면 삭제 버튼이 나타나고, 삭제 전에는 항상 한 번 더 확인합니다. 항목 상세 보기 모달에서도 "삭제" 버튼으로 바로 지울 수 있습니다.

### 5. 정렬 & 요약
- 우선순위순 · 최근 추가순 · 가격 낮은순 · 가격 높은순으로 정렬할 수 있습니다. (정렬 드롭다운 옆에 ▾ 아이콘이 있어 클릭 가능한 요소임을 표시해요.)
- "살 것" 탭 상단에는 현재 선택한 카테고리 필터 기준으로 아직 안 산 항목의 총개수와 합계 금액이 요약돼서 보입니다 (가격을 안 적은 항목은 개수에는 포함되지만 합계에서는 제외돼요).

### 6. 필요도 / 만족도를 각각 확인
- 우선순위는 하나의 별점으로 뭉치지 않고, 카드와 상세 보기에서 "필요"·"만족" 두 별점으로 각각 보여줍니다. 필요도 × 욕구는 결국 2축으로 나뉘는 개념이라, 합쳐서 하나로 보여주면 정보가 사라지기 때문이에요.

## 💾 데이터는 어디에 저장되나요?

WishBox는 **서버 없이 브라우저 안에서만 동작하는 로컬 전용 앱**입니다.

- 입력한 모든 데이터는 브라우저의 **IndexedDB**에 저장됩니다. (`Dexie.js`로 관리)
- 별도의 로그인이나 서버 동기화가 없어서, **이 브라우저·이 기기에서만** 데이터가 보입니다.
- 브라우저 캐시/사이트 데이터를 지우거나 시크릿 모드로 접속하면 저장된 항목이 사라질 수 있으니 주의해주세요. (앱 첫 진입 시 이 안내가 한 번 노출됩니다.)
- 다만 데이터 구조는 단순하게 설계해서, 나중에 클라우드 동기화가 필요해지면 Supabase 등으로 옮기기 쉽게 만들어뒀습니다.

## 🚀 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 열면 됩니다.

다른 명령어:

```bash
npm run build   # 프로덕션 빌드
npm run start   # 빌드된 앱 실행
npm run lint    # 코드 검사
```

## 📁 폴더 구조

```
app/                        # Next.js App Router 페이지, 전역 스타일
components/                 # 화면을 구성하는 UI 컴포넌트
  ui/                        # 버튼, 칩, 모달 등 공용 컴포넌트
lib/
  db.ts                      # IndexedDB 스키마 및 CRUD 함수 (items / categories / item_categories)
  useWishBoxData.ts          # 데이터 로드·갱신, 기본 카테고리 시딩을 담당하는 훅
  priority.ts                # 필요도 × 욕구 매트릭스 계산 로직
  format.ts                  # 가격 포맷, URL 검증 등 유틸
docs/                        # 기획/디자인 문서
```
