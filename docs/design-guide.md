# 🎨 [디자인 가이드] IT 부캐 찾기 프로젝트

## 1. 컬러 팔레트
- **페이퍼 화이트** `#FAF9F6` — 전체 배경
- **카드 화이트** `#FFFFFF` — 카드/모달 배경
- **잉크 네이비** `#1F2430` — 본문 텍스트
- **그레이** `#8A8F99` — 태그, 날짜 등 보조 텍스트
- **박스 블루** `#3555D8` — 브랜드 컬러 (버튼, 액티브 탭)
- **시그널 코랄** `#FF6452` — 우선순위 강조 전용 (과사용 금지)
- **세이지 그린** `#4C9A6A` — 구매완료 상태 표시

## 2. 타이포그래피
- **제목**: Pretendard Bold, 20~24px
- **본문**: Pretendard Regular/Medium, 15~16px
- **보조 텍스트**: Pretendard Regular, 12~13px, 그레이 컬러 적용

## 3. 레이아웃 & 컴포넌트

- 카드 간 간격 12px / 카드 내부 패딩 16px / 버튼 높이 44px (모바일 터치 고려)
- 버튼: 모서리 둥글기 8px, Primary(박스 블루 배경) / Secondary(테두리만)
- 태그 칩: 완전 둥근 필(pill) 형태, 선택 시 박스 블루 배경으로 전환
- 우선순위 별점: 채워진 별은 코랄, 빈 별은 그레이 테두리

## 4. 빈 상태(Empty State) 문구

- 리스트 비어있을 때: `아직 담아둔 게 없어요. 사고 싶은 걸 지금 추가해보세요.`
- "산 것" 탭 비어있을 때: `아직 산 게 없어요. 체크하면 여기 모여요.`
